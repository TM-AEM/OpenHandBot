## 3. التحقّق المستقل من F-01 — ثابتا I7/I8

**المصدر الحاسم (المقترح r12 §8.1):**
- `| I7 | Accompanying text required before sending | files alone never dispatch |`
- `| I8 | No sending files without accompanying text | dispatch only on text within deadline |`
- داعم: §8.2 `S1` («On first file … persist `T0` … reply «في انتظار أوامرك»»)، §10.2 («Files without text
  never dispatch; non-text messages never trigger sending»)، §5.10.2 («Once valid accompanying text
  arrives before the deadline (L1)»).

**النتيجة:** ✅ **مُصلَح بشكل صحيح.**

1. **التمثيل في §11:** البند **15 (I7)** والبند **16 (I8)** — صريحان وموسومان بالمعرّف.
2. **وفاء الصياغة:** بند 15 = «الملفات وحدها لا تُرسِل أبدًا؛ لا إرسال تلقائي بمجرّد وصول الملف» ⇒ يطابق
   «files alone never dispatch» بدقّة. بند 16 = «الإرسال فقط عند وصول نص مصاحب داخل المهلة؛ وتبدأ مهلة
   الـ15 دقيقة عند استلام الملف؛ والرسائل غير النصية لا تُفعِّل الإرسال» ⇒ يطابق «dispatch only on text
   within deadline» + S1 + «non-text messages never trigger sending» بدقّة.
3. **الإحالة في D-01:** القسم A يذكر `§8.1 I7/I8` + قيد ثابت «لا يُنشئ إرسالًا تلقائيًا ولا fallback إلى
   محادثة جديدة» (L180-186). ✅
4. **التمييز بين الوصول/الجمع/المُفعِّل:** بند 16 يربط العدّ بـ**استلام الملف** والإرسال بـ**النص داخل
   المهلة**؛ D-01 يصف «مرحلة message-accept» منفصلة عن المُفعِّل؛ §6.1 بند 6 يسمّي «آلة حالة المرفقات
   المعلّقة». ⇒ التمييز محفوظ (وصول الملف ≠ تفعيل الإرسال). ✅
5. **قاعدة «الملفات وحدها لا تُرسِل»:** صريحة في بند 15 وD-01. ✅
6. **لا خيار/توصية في D-01 يناقض I7/I8:** الخيارات A–D كلها عن **إشارة القبول (`consumed_at`)** لا عن
   الإرسال؛ التوصية (C) لا تُرسِل ملفات. ✅
7. **لا إدخال إرسال تلقائي/مهلة-تُرسِل/fallback:** بحث مباشر: «إرسال تلقائي» يظهر فقط كـ**نفي** في §11
   بند 15 وD-01؛ لا «timeout-send»؛ لا fallback إلى محادثة جديدة (يظهر فقط كـ**نفي**). ✅

**سؤال «النص المؤهِّل»:** تحقّقتُ مباشرةً أن المقترح **لا يعرّف** «valid/qualifying text» (لا يوجد تعريف
في §5.10.2 ولا §10.2 ولا §8.4 — فقط الاستعمال). والسجل **لم يختلق** تعريفًا ولم يعامل الالتباس كسلوك
مُعتمَد (كل الخيارات مفتوحة). ⇒ حدّ R1 المُعلن **صحيح** (انظر R1-F-04 كملاحظة شفافية).
